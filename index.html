04 / IA ONLINE

Escolha sua inteligência artificial

Conecte-se com sua própria chave de API. A chave fica no navegador e não é salva no GitHub.

A chave não é enviada ao RobotMario-AI nem gravada no arquivo do projeto; ela é enviada diretamente ao provedor escolhido. Não use uma chave em computador compartilhado. O uso pode gerar cobranças conforme sua conta.

05 / SMM:WE

Conversor JSON ↔ .swe

Importe um .swe para decodificar o conteúdo ou cole o JSON de uma fase para gerar um arquivo .swe.

O conversor segue o método do código enviado: JSON minificado → Base64 UTF-8 → HMAC-SHA1 de 40 caracteres hexadecimais. A compatibilidade com todas as versões do jogo ainda precisa ser testada. Não envie arquivos pessoais ou chaves de API neste campo.
